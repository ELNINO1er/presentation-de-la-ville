# IVORA Immobilier — Présentation de la ville d'Abidjan

Site vitrine immobilier animé consacré à Abidjan et à la Côte d'Ivoire : vivre et investir.

**En ligne :** https://elnino1er.github.io/presentation-de-la-ville/

## Contenu

- Hero animé, vidéo aérienne d'Abidjan avec zoom au défilement
- Portefeuille de biens (appartements, villas, location) avec carte interactive
- Chiffres animés, solutions sur mesure, « chemin vers la propriété » en cercles qui fusionnent
- Pourquoi la Côte d'Ivoire, types de biens en mosaïque parallaxe, partenaires, FAQ, footer

## Technique

HTML / CSS / JavaScript statique, sans étape de build.
Bibliothèques chargées par CDN : GSAP + ScrollTrigger, Lenis, Leaflet (cartes OpenStreetMap).

Lancer en local : ouvrir `index.html` via un serveur (WAMP, `npx serve`, etc.).
